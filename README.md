# Rated

Rated is an Android app for discovering, rating, and reviewing things with a community. Users can create entries, share their opinions, build profiles, and connect with other reviewers.

## Features

- **Ratings and reviews**: Share ratings and written reviews.
- **Community entries**: Create and discover entries.
- **User profiles**: Customize your profile and explore other users.
- **Social features**: Follow users, view followers, and interact with the community.
- **Direct messages**: Message other users where supported by the server.
- **Content controls**: Block users and report inappropriate content.
- **Custom servers**: Connect to a supported public or private server.
- **Web access**: Use the companion website to explore Rated and access documentation.

## Download

Get the latest Android release from the [GitHub Releases page](https://github.com/NicelyTinned/ratings-app/releases).
If no release is available yet, check back later or build the project from source.

## Custom Servers

Rated supports connecting to compatible servers. Server availability and features depend on the server configuration.

See the project website's [/docs](https://rated-app.pages.dev/docs) page for setup instructions, including how to configure a private server.

## Technology

- **Android**: Native Android application
- **Backend**: Cloudflare Workers
- **Database**: Cloudflare D1
- **Website**: Static web application

## Development Status

Rated is under active development. Features, server compatibility, and setup instructions may change between releases.

## Contributing

Contributions, bug reports, and feature suggestions are welcome. Please open an issue before starting major changes so proposed work can be discussed.

## Security and Privacy

Use a trusted server and avoid sharing sensitive personal information in reviews or messages. Server operators may be able to access data stored on their servers. Direct messages should not be assumed to be end-to-end encrypted.
